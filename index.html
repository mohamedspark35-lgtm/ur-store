الأسئلة الشائعة

كل اللي محتاج تعرفه قبل الطلب

لا، الموقع مخصص لاختيار المنتج وإرسال تفاصيل الطلب. بعد ذلك يتم التواصل معك عن طريق WhatsApp لتنفيذ الطلب.
يتم إنشاء رقم طلب تلقائيًا عند الضغط على "اطلب الآن"، ويظهر لك داخل بيانات الطلب ويتم إرساله في رسالة WhatsApp.
نعم، عند طلب منتجات PUBG Mobile يجب إدخال Player ID الصحيح.
لا، لن تظهر خانة Player ID عند اختيار منتجات eFootball.
يتم استلام طلبك والتواصل معك لتنفيذ العملية، وبعد إتمام الشحن يتم تأكيد إتمام العملية معك عبر WhatsApp.
